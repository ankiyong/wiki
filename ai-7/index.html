1. 2026 GPT 기능 지도

영상에서는 GPT를 단순 채팅 도구가 아니라 모델 선택, 앱 연동, 에이전트, 리서치, 문서 편집, 프로젝트 관리까지 확장된 작업 공간으로 설명합니다.

모델 선택Instant / Thinking / Pro / Auto처럼 속도와 깊이에 맞춰 선택
앱 연동Adobe Express, Photoshop, Figma 등 외부 도구와 연결
Agent Mode웹과 연결 서비스에서 다단계 업무 수행

핵심: 기능을 많이 아는 것보다 “어떤 결과가 필요한지”에 맞춰 모드를 고르는 것이 중요합니다.

2. Chat / Work / Codex 선택법

선택 기준은 주제가 아니라 최종 결과물입니다.

Chat

답변만 빠르게 필요할 때

  • 질문
  • 개념 설명
  • 짧은 요약
  • 문장 다듬기
GPT Work

업무 산출물을 완성할 때

  • 시장조사
  • 보고서
  • 발표자료
  • 스프레드시트
  • 회의록·정기 리포트
Codex

코드를 바꾸고 검증할 때

  • 버그 수정
  • 기능 구현
  • 리팩터링
  • 테스트·빌드
  • PR 검토·배포 준비

한 문장 요약: 업무 자료는 Work, 코드 변경은 Codex, 빠른 답변은 Chat입니다.

3. GPT Work와 Codex 비교

Work는 자료와 산출물이 중심이고, Codex는 작업공간과 검증이 중심입니다.

기준GPT WorkCodex
핵심 목표검토 가능한 업무 결과 완성검증된 기술 변경 완성
주요 맥락문서, 웹, 파일, 플러그인, 연결 서비스저장소, 소스코드, 로그, 터미널
대표 결과보고서, 슬라이드, 표, PDF, 사이트 초안코드 변경, 테스트, 리뷰, 빌드 결과
검토 기준내용, 구조, 출처, 시각적 완성도diff, 테스트, 타입 검사, 실행 결과
좋은 요청대상 독자, 자료 범위, 형식, 품질 기준작업 위치, 재현 조건, 제약, 검증 명령

4. Work 실습 — 업무 산출물 요청

Work 요청은 결과물, 자료 범위, 대상 독자, 형식, 품질 기준, 승인 지점을 구체적으로 써야 합니다.

요청 공식

결과물 + 자료 범위 + 대상 독자 + 형식 + 품질 기준 + 승인 지점

실습 프롬프트

첨부한 회의록 5개를 바탕으로 결정사항, 담당자별 할 일, 마감일, 리스크를 표로 정리해줘. 대상은 팀장 보고용이고, 분량은 1페이지 이내로 해줘. 근거가 부족한 내용은 “확인 필요”라고 표시해줘. 외부로 전송하지 말고 초안만 만들어줘.

Work는 “사람이 검토하고 바로 활용할 업무 자료”를 만들 때 가장 자연스럽습니다.

5. Codex 실습 — 기술 작업 요청

Codex 요청은 작업 위치, 문제, 재현 방법, 제약, 검증 명령, 보고 형식이 중요합니다.

요청 공식

작업 위치 + 문제/목표 + 재현 방법 + 제약 + 검증 명령 + 보고 형식

실습 프롬프트

현재 저장소에서 로그인 후 세션이 만료되는 문제를 재현해줘. 원인을 찾은 뒤 최소 범위로 수정하고, 관련 회귀 테스트를 추가해줘. 데이터베이스 스키마는 바꾸지 말고, 수정 후 인증 관련 테스트를 실행해서 원인, 변경 파일, 테스트 결과, 남은 위험을 요약해줘.

Codex는 설명만 하는 것이 아니라 파일 변경과 테스트 결과로 작업을 증명해야 할 때 적합합니다.

6. 함께 쓰는 업무 흐름

복잡한 프로젝트는 Work와 Codex를 연결하면 더 안정적입니다.

1. Work조사·요구사항·기획 자료 작성
→
2. Codex저장소 분석·구현·테스트
→
3. Work릴리스 노트·고객 공지·교육자료 작성
예시 1Work로 경쟁사 분석표 작성 → Codex로 기능 구현 → Work로 발표자료 작성
예시 2Codex로 버그 수정 결과 정리 → Work로 고객 안내문과 내부 보고서 작성

중간에는 반드시 사람이 승인합니다: 조사 → 요구사항 승인 → 구현 → 테스트 확인 → 공지 작성.

7. 보안·승인·검토

도구가 강력할수록 입력 자료, 권한, 외부 동작을 더 명확히 통제해야 합니다.

Work 주의메일 전송, 게시, 캘린더 수정, 외부 시스템 변경 전에는 승인 지점을 둡니다.
Codex 주의작업 폴더, 쓰기 권한, 네트워크, 삭제·배포·푸시 권한을 제한합니다.
공통 주의개인정보, 비밀키, 내부 민감 문서, 고객 정보는 입력하지 않습니다.
최종 확인출처, 숫자, 코드 변경, 테스트 범위, 보안 위험을 사람이 검토합니다.

오늘 기억할 문장

완성된 업무 자료는 Work, 검증된 코드 변경은 Codex, 빠른 답변은 Chat입니다.
