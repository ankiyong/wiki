AI-3. ChatGPT 유료 기능·GPTs·Skill 생성 실습

앞부분은 유료 기능을 빠르게 체험하고, 후반부는 GPTs와 Skill 생성으로 나만의 AI 도구를 완성합니다.

수업 목차 0. 수업 목표 1. 실습 1 — 유료 기능 워밍업 2. 실습 2 — 파일·이미지·표 분석 3. 실습 3 — 나만의 GPT 설계 4. 실습 4 — GPT 만들기와 테스트 5. 실습 5 — Skill 생성 6. 실습 6 — GPTs+Skill 패키지 완성 7. 오늘 완성할 결과물

0. 수업 목표

ChatGPT 유료 기능을 단순히 써보는 데서 끝내지 않고, 반복 업무를 처리하는 나만의 GPT와 Skill로 만드는 것이 목표입니다.

ChatGPT 유료 기능GPTsSkill 생성실습 중심
  • ChatGPT 유료 기능으로 파일, 이미지, 표, 긴 글을 빠르게 처리한다.
  • 내 업무에 맞는 GPT 목적·지침·대화 시작문을 설계한다.
  • GPT에 넣을 지식 자료와 테스트 질문을 준비한다.
  • 반복 업무를 Skill 카드로 정리해 GPT에 재사용 가능하게 넣는다.
  • 최종적으로 “내가 계속 쓸 수 있는 GPT + Skill 패키지”를 만든다.

1. 실습 1 — 유료 기능 워밍업

처음 15~20분은 ChatGPT 유료 기능을 짧게 체험합니다. 핵심은 기능 소개가 아니라 “어떤 일을 맡길 수 있는지” 감을 잡는 것입니다.

기능실습산출물
긴 답변 정리복잡한 주제를 짧게 재구성3줄 요약 + 쉬운 설명
문장 다듬기딱딱한 글을 자연스럽게 수정공식/친근/짧은 버전
아이디어 확장주제 하나를 여러 방향으로 확장아이디어 후보 10개
역할 부여상황에 맞는 전문가 역할 지정맞춤형 답변 구조

실습 프롬프트

너는 내가 반복 업무를 AI로 줄일 수 있게 도와주는 실무 코치야.

아래 주제를 바탕으로 다음을 만들어줘.
1. 3줄 요약
2. 초보자도 이해할 쉬운 설명
3. 바로 해볼 수 있는 실습 아이디어 5개
4. 이 주제로 만들 수 있는 GPT 아이디어 3개

[주제]
여기에 내가 다루고 싶은 업무나 관심사를 입력

2. 실습 2 — 파일·이미지·표 분석

유료 기능의 장점을 활용해 자료를 업로드하고, 요약·분류·표 정리·질문 목록을 만듭니다.

파일
PDF, 문서, 회의자료, 안내문 요약
이미지
사진, 캡처, 포스터 내용 설명
표
CSV, 엑셀, 설문 결과 정리
결과
요약표, 확인 질문, 다음 작업 목록

실습 프롬프트

업로드한 자료를 분석해서 다음 형식으로 정리해줘.

1. 핵심 요약 5줄
2. 표로 정리할 수 있는 정보
3. 중요한 숫자·날짜·조건
4. 내가 다음에 해야 할 일
5. GPT나 Skill로 만들면 반복 처리할 수 있는 부분
6. 사람이 다시 확인해야 할 부분

자료에 없는 내용은 추측하지 말고 “확인 필요”라고 표시해줘.

3. 실습 3 — 나만의 GPT 설계

GPTs는 특정 목적에 맞게 지침, 지식, 기능을 설정한 맞춤형 ChatGPT입니다. 먼저 만들 GPT의 목적과 사용 장면을 설계합니다.

설계 항목질문
목적이 GPT는 어떤 일을 도와주는가?
대상누가 사용할 것인가?
입력자료사용자가 어떤 자료를 넣는가?
출력형식표, 체크리스트, 보고서, 이메일 중 무엇을 내보내는가?
금지사항어떤 답변이나 요청을 피해야 하는가?

내가 만들 GPT를 설계하고 싶어.

[이 GPT를 사용할 사람]

[GPT가 받아야 할 입력자료]

[GPT가 만들어야 할 결과물]

[주의해야 할 점]

4. 실습 4 — GPT 만들기와 테스트

설계안을 바탕으로 GPT Builder에서 이름, 설명, Instructions, Knowledge, Capabilities를 설정하고 테스트합니다.

1단계

2단계
Instructions 붙여넣기
3단계

4단계

검토 기준:
1. 역할이 분명한가?
2. 사용자의 입력을 어떻게 처리할지 명확한가?
3. 출력 형식이 정해져 있는가?
4. 하지 말아야 할 행동이 들어가 있는가?

개선된 Instructions와 테스트 질문 5개를 작성해줘.

5. 실습 5 — Skill 생성

여기서 Skill은 반복 업무를 GPT가 일관되게 처리하도록 만든 절차 카드입니다. 버튼 하나로 끝나는 기능이 아니라, “언제 쓰고, 어떤 순서로 처리하고, 어떤 결과를 내야 하는지”를 정리한 재사용 지침입니다.

Skill 구성내용
언제 사용이 Skill이 필요한 상황
입력자료사용자가 넣어야 하는 정보
작업 절차GPT가 따라야 할 순서
출력형식최종 결과물의 모양
검토 기준사람이 확인해야 할 항목

내 반복 업무를 GPT에 넣을 Skill 형태로 정리하고 싶어.

[원하는 결과물]

[주의할 점]

6. 실습 6 — GPTs+Skill 패키지 완성

마지막에는 GPT 설계안과 Skill 카드를 합쳐 실제로 계속 사용할 수 있는 패키지로 정리합니다.

패키지 요소완성 기준
GPT 이름사용 목적이 바로 보인다
Instructions역할, 절차, 출력형식, 금지사항이 들어 있다
Knowledge반복 참고자료 또는 예시가 들어 있다
Skill 카드업무 절차와 검토 기준이 명확하다
테스트 질문실제 사용 상황 3개 이상으로 검증했다
