2. Docs 회의 메모 정리

실습자료의 `01_docs_meeting_memo.md` 내용을 Google Docs에 붙여넣고, Gemini로 안내문과 실행 목록을 만듭니다.

내가 할 일원문을 Docs에 붙여넣고 Gemini에게 쉬운 안내문으로 바꿔 달라고 요청합니다.
남길 결과`20260818_지역축제_안내문_AI초안` 문서와 사람이 고친 수정본을 저장합니다.

문서 정리 프롬프트

이 회의 메모를 지역 주민에게 보낼 안내문으로 바꿔줘. 조건: 1. 행사 개요, 프로그램, 신청 안내, 준비물, 문의처 순서로 정리해줘. 2. 아직 확정되지 않은 내용은 [확인 필요]로 표시해줘. 3. 문장은 짧고 쉽게 써줘. 4. 마지막에 담당자가 해야 할 실행 목록을 체크리스트로 만들어줘. 5. 원문에 없는 사실은 추가하지 마.

문체 바꾸기 프롬프트

방금 만든 안내문을 다시 다듬어줘. 버전 1: 기관 공지문처럼 단정하게 버전 2: 수강생 안내문처럼 친절하게 버전 3: 카드뉴스 문구처럼 짧게 각 버전마다 제목 후보도 3개씩 제안해줘.

3. Sheets 피드백 분류

실습자료의 `02_sheets_feedback_samples.csv`를 Google Sheets로 열고, 수강생 피드백을 분류합니다.

긍정좋았던 점, 계속 유지할 점
어려움로그인, 속도, 개념 혼동
개선다음 수업에 바꿀 점

피드백 분류 프롬프트

이 표는 수강생 피드백이야. 각 문장을 `긍정 / 어려웠던 점 / 개선 요청 / 다음 강의 반영`으로 분류해줘. 결과는 표로 정리해줘. 각 분류마다 대표 문장 2개와 강사가 바로 할 다음 액션 1개를 제안해줘.

작업 기록표 프롬프트

내가 AI로 처리한 업무를 기록하는 표를 만들고 싶어. 열은 날짜, 업무명, 입력자료, AI에 요청한 내용, AI 결과 요약, 사람이 수정한 점, 재사용 가능 여부, 다음 액션으로 해줘. 첫 번째 예시 행도 하나 만들어줘.

4. Slides 발표 흐름 만들기

Docs에서 정리한 안내문이나 Sheets 분석 결과를 5장 발표 흐름으로 바꿉니다.

1장오늘의 주제와 왜 중요한가
2장핵심 내용 3가지
3장표나 사례로 보는 결과
4~5장실행 계획과 다음 행동

Slides 구성 프롬프트

이 문서 내용을 10분 발표자료 5장으로 구성해줘. 각 장표마다 다음을 써줘. 1. 장표 제목 2. 핵심 메시지 한 문장 3. 들어갈 예시나 표 4. 발표자가 말할 한 문장 청중은 생성형 AI를 처음 배우는 성인이야.

5. NotebookLM 지식창고 만들기

실습자료의 `05_notebooklm_source_packet.md`와 오늘 만든 Docs 요약본을 NotebookLM 소스로 넣습니다.

소스 넣기실습 문서, 요약본, 영상 링크를 추가합니다.
질문하기내가 넣은 자료만 근거로 요약·FAQ·활동 아이디어를 만듭니다.
저장하기좋은 답변은 Docs나 Drive 폴더에 복사해 둡니다.
확인하기자료에 없는 말을 지어내지 않는지 봅니다.

NotebookLM 질문 프롬프트

이 노트북에 넣은 자료만 근거로 답해줘. 1. 핵심 내용을 초보자도 이해할 수 있게 5문장으로 요약해줘. 2. 수업이나 업무에 바로 쓸 수 있는 아이디어 3개를 제안해줘. 3. 헷갈릴 수 있는 용어 5개를 쉬운 말로 풀어줘. 4. 자료에 근거가 부족한 내용은 [확인 필요]로 표시해줘.

6. YouTube 요약 저장하기

공개 YouTube 영상을 요약한 뒤, 그냥 지나치지 말고 Docs와 NotebookLM에 저장합니다.

요약핵심 주장, 사례, 배울 점을 분리합니다.
출처영상 제목, 채널, URL, 확인 날짜를 남깁니다.
재사용강의 아이디어, 블로그 소재, 질문 목록으로 바꿉니다.
주의영상 내용을 그대로 베끼지 않고 내 목적에 맞게 요약합니다.

YouTube 요약 프롬프트

이 YouTube 영상을 학습 노트로 정리해줘. 조건: 1. 영상의 핵심 내용을 5문장으로 요약해줘. 2. 중요한 사례를 3개만 뽑아줘. 3. 내가 업무나 수업에 적용할 아이디어를 3개 제안해줘. 4. 그대로 인용하면 안 되는 내용과 직접 확인할 내용을 따로 표시해줘. 5. 마지막에 출처 기록 형식을 만들어줘. 링크: 여기에 YouTube URL 붙여넣기

7. Deep Research 결과 검토

Deep Research는 조사 초안을 빠르게 만드는 도구입니다. 결과를 받은 뒤에는 주장과 출처를 직접 확인합니다.

실습자료 `04_deep_research_review_template.csv`에 `주장 / 출처 / 신뢰도 / 수업 반영 여부 / 확인 필요`를 채웁니다.

Deep Research 요청 프롬프트

주제: 성인 대상 Google Gemini + Workspace 활용 교육 아이디어 조사 조사 범위: Google 공식 자료, 교육기관 사례, 2025~2026년 AI 리터러시와 업무 활용 흐름 제외: 광고성 블로그, 출처가 불분명한 글 결과 형식: 1. 핵심 트렌드 5개 2. 수업에 넣을 실습 아이디어 5개 3. 수강생에게 알려야 할 주의점 5개 4. 확인한 출처 목록 5. 바로 수업에 반영할 3시간 실습 흐름

출처 검토 프롬프트

아래 조사 결과를 검토표로 바꿔줘. 열은 `주장 / 출처 링크 / 출처 유형 / 신뢰도 / 수업에 반영할 내용 / 확인 필요 사항`으로 해줘. 출처가 약하거나 최신성이 부족한 내용은 신뢰도를 낮게 표시해줘.

8. 나만의 업무 시스템 완성

마지막에는 오늘 만든 결과물을 Drive에 모으고, 다음에 다시 쓸 수 있는 프롬프트와 파일명 규칙을 남깁니다.

  • Drive 폴더에 원본자료, AI요약, 수정본, 발표자료가 들어 있는지 확인합니다.
  • Docs 안내문에서 [확인 필요] 항목을 따로 모읍니다.
  • Sheets 분석 결과에서 다음 행동 3개를 정합니다.
  • NotebookLM에 오늘 자료를 넣고 다시 질문할 수 있는지 확인합니다.
  • 좋았던 프롬프트 3개를 저장합니다.

마무리 점검 프롬프트

오늘 만든 결과물을 기준으로 내 AI 업무 시스템을 점검해줘. 아래 형식으로 정리해줘. 1. 내가 만든 파일 목록 2. 바로 업무에 쓸 수 있는 결과물 3. 사람이 반드시 확인해야 할 내용 4. 다음에 재사용할 프롬프트 3개 5. 내 Drive에 저장할 파일명 추천
