AI-4. Gemini × SunoAI 음악 만들기 실습

Gemini로 SunoAI에 넣을 가사와 음악 프롬프트를 만들고, SunoAI에서 실제 음악 제작까지 이어갑니다.

0. 수업 목표

오늘 수업은 Gemini를 “생각 정리 도구”로 쓰고, SunoAI를 “음악 제작 도구”로 연결하는 실습입니다.

GeminiSunoAI가사 프롬프트음악 프롬프트
  • Gemini에게 프롬프트를 만들어 달라고 요청하는 방법을 익힌다.
  • SunoAI가 어떤 도구인지 이해한다.
  • Gemini로 SunoAI용 가사 생성 프롬프트를 만든다.
  • Gemini로 SunoAI용 음악 생성 프롬프트를 만든다.
  • SunoAI에 넣을 최종 입력문을 완성한다.

1. 실습 1 — Gemini로 프롬프트 만드는 방법

먼저 Gemini에게 “내가 직접 프롬프트를 잘 쓰는 법”이 아니라, 프롬프트 자체를 만들어 달라고 요청하는 법을 연습합니다.

넣을 정보예시
목적SunoAI에서 노래를 만들고 싶다
주제청년의 도전, 여행, 가족, 지역 축제, 수업 후기
분위기밝게, 감성적으로, 신나게, 잔잔하게
결과 형식SunoAI에 바로 붙여넣을 수 있는 문장

실습 프롬프트

너는 AI 음악 제작을 도와주는 프롬프트 코치야.

내가 SunoAI에서 음악을 만들 수 있도록 필요한 질문을 먼저 해주고,
내 답변을 바탕으로 SunoAI에 넣을 프롬프트를 만들어줘.

먼저 나에게 아래 5가지를 질문해줘.
1. 노래 주제
2. 듣는 대상
3. 원하는 분위기
4. 넣고 싶은 핵심 단어
5. 피하고 싶은 표현

2. 실습 2 — SunoAI 소개

SunoAI는 텍스트 설명을 바탕으로 노래를 만들어 주는 AI 음악 생성 도구입니다. 수업에서는 완성곡보다 좋은 입력문을 만드는 과정에 집중합니다.

가사
주제, 메시지, 절, 후렴 구조를 정리해 입력합니다.
음악 스타일
장르, 분위기, 악기, 속도, 보컬 느낌을 입력합니다.
생성
SunoAI에서 후보 음악을 만들고 들어봅니다.
수정
마음에 안 드는 부분을 다시 프롬프트로 수정합니다.

실습 프롬프트

SunoAI를 처음 사용하는 사람에게 설명한다고 생각하고,
아래 내용을 쉽게 정리해줘.

1. SunoAI로 할 수 있는 일
2. 음악을 만들 때 필요한 입력 정보
3. 가사 프롬프트와 음악 스타일 프롬프트의 차이
4. 처음 실습할 때 주의할 점
5. 내가 지금 바로 해볼 수 있는 간단한 예시

3. 실습 3 — SunoAI용 프롬프트 만들기

이 단계부터는 Gemini를 활용해 SunoAI에 넣을 입력문을 만듭니다. 핵심은 가사와 음악 스타일을 분리해서 만드는 것입니다.

구분Gemini에서 만드는 것SunoAI에서 쓰는 곳
가사 생성 프롬프트주제, 메시지, 절/후렴, 표현 톤Lyrics 또는 가사 입력
음악 생성 프롬프트장르, 분위기, 악기, 보컬, 속도Style of Music 또는 음악 설명 입력
실습 순서: 주제 정하기 → Gemini로 가사 프롬프트 만들기 → Gemini로 음악 스타일 프롬프트 만들기 → SunoAI에 입력하기

3-1. Gemini에서 SunoAI용 가사 생성 프롬프트 만들기

가사 프롬프트는 노래가 “무슨 이야기를 할지”를 정하는 단계입니다. 너무 추상적으로 쓰기보다 대상, 장면, 메시지를 구체화합니다.

항목입력 예시
주제새로운 시작을 앞둔 청년의 마음
대상20대 청년, 취업 준비생, 수업 참여자
핵심 메시지불안해도 한 걸음씩 가면 된다
가사 구조Verse 1 / Chorus / Verse 2 / Bridge / Chorus
표현 톤쉽고 따뜻하게, 너무 오글거리지 않게

실습 프롬프트

너는 SunoAI용 가사 프롬프트를 만드는 작사가야.

아래 조건을 바탕으로 SunoAI에 넣을 가사 생성 프롬프트를 만들어줘.

[노래 주제]
새로운 시작을 앞둔 청년의 마음

[듣는 대상]
20대 청년, 취업 준비생, 수업 참여자

[핵심 메시지]
불안해도 한 걸음씩 가면 된다

[분위기]
따뜻하고 희망적이지만 너무 과장되지 않게

[가사 구조]
Verse 1 / Chorus / Verse 2 / Bridge / Chorus

[조건]
- 한국어 가사
- 쉬운 단어 사용
- 너무 오글거리는 표현 피하기
- 후렴은 따라 부르기 쉽게
- SunoAI에 바로 붙여넣을 수 있게 작성

3-2. Gemini에서 SunoAI용 음악 생성 프롬프트 만들기

음악 생성 프롬프트는 노래가 “어떤 소리로 들릴지”를 정하는 단계입니다. 장르, 악기, 속도, 보컬 느낌을 구체적으로 적습니다.

항목입력 예시
장르K-pop ballad, acoustic pop, indie pop
분위기warm, hopeful, emotional, uplifting
악기acoustic guitar, soft piano, light drums
보컬clear Korean vocal, warm male/female vocal
속도mid-tempo, not too slow

실습 프롬프트

너는 SunoAI용 음악 스타일 프롬프트를 만드는 음악 프로듀서야.

아래 가사 분위기에 어울리는 음악 생성 프롬프트를 만들어줘.

[가사 분위기]
새로운 시작을 앞둔 청년에게 따뜻하게 응원하는 노래

[원하는 장르]
K-pop ballad + acoustic pop

[원하는 감정]
warm, hopeful, emotional, uplifting

[악기]
acoustic guitar, soft piano, light drums

[보컬]
clear Korean vocal, warm and sincere tone

[조건]
- SunoAI의 Style of Music 칸에 바로 넣을 수 있게 영어 중심으로 작성
- 너무 복잡하지 않게 한 문단으로 작성
- 장르, 분위기, 악기, 보컬, 속도가 모두 포함되게 작성
- 마지막에 대체 스타일 3개도 제안해줘

4. 오늘 완성할 결과물

  1. Gemini로 만든 프롬프트 설계 질문 1개
  2. SunoAI용 가사 생성 프롬프트 1개
  3. SunoAI용 음악 생성 프롬프트 1개
  4. SunoAI에 입력할 최종 가사/스타일 세트 1개

한 줄 정리: Gemini는 음악을 만들기 전 생각을 정리하는 도구이고, SunoAI는 그 정리된 입력을 바탕으로 음악을 만드는 도구입니다.
