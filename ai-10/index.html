0. 오늘 완성할 결과물

오늘 수업의 기본 구조는 두 가지입니다. 하나는 그때그때 쓰는 기본 요청, 다른 하나는 반복해서 쓰는 프로젝트입니다. 둘 다 사용자는 긴 글을 치지 않고, AI가 먼저 필요한 내용을 질문하고, 사용자는 음성으로 답합니다.

좋은 프롬프트를 외우는 수업이 아니라, AI가 나에게 필요한 질문을 하게 만들고 내가 말로 답하는 방식으로 AI를 쓰는 수업입니다.

1. 기본 요청 구조

기본 요청은 한 번만 처리하면 되는 일에 사용합니다. 처음부터 완벽한 설명을 하지 않아도 됩니다. AI에게 먼저 질문하라고 시키면 됩니다.

1프롬프트 입력
2AI가 부족한 내용 질문
3사용자가 음성으로 답
4AI가 초안 작성
5사람이 확인

기본 요청 말하기 예시

마이크 버튼을 누르고 이렇게 말해보세요. 나는 [하고 싶은 일]을 하려고 해. 바로 결과를 만들지 말고, 좋은 답을 만들기 위해 나에게 필요한 내용을 먼저 질문해줘. 질문은 한 번에 하나씩 쉽게 해줘. 내가 음성으로 답하면 그 내용을 바탕으로 결과를 만들어줘. 마지막에는 내가 확인해야 할 점도 알려줘.
쓸 수 있는 일여행 계획, 안내문, 문자, 블로그 글, 일정표, 비교표, 준비물 목록, 취미 계획

2. AI가 물어보게 만들기

사용자가 처음부터 모든 정보를 말하지 않아도 되도록, AI가 필요한 내용을 묻게 만드는 것이 핵심입니다.

목적무엇을 만들까요?
대상누구에게 보여줄까요?
상황현재 조건은 무엇인가요?
형식표, 목록, 문장 중 무엇이 좋을까요?
주의개인정보, 주소, 연락처, 건강·금융·법률처럼 민감한 내용은 말하지 않습니다.

AI가 할 질문을 정해주는 말하기 예시

내가 답하기 쉽게 질문해줘. 질문은 목적, 대상, 상황, 조건, 출력 형식 순서로 해줘. 한 번에 여러 질문을 하지 말고 하나씩 물어봐. 내 답이 짧거나 애매하면 쉬운 추가 질문으로 확인해줘. 필요한 질문을 다 한 뒤에 최종 결과를 만들어줘.

사용자가 음성으로 답할 때의 예시

대상은 가족이야. 말투는 너무 딱딱하지 않게 해줘. 길이는 문자로 보낼 수 있게 짧게 해줘. 빠진 내용이 있으면 네가 다시 물어봐줘.

3. 프로젝트 구조

프로젝트는 자주 반복하는 일에 사용합니다. 매번 처음부터 설명하지 않도록, 먼저 지침을 넣어두고 작업을 요청할 때마다 AI가 필요한 내용을 질문하게 합니다.

1지침 입력
2작업 요청
3AI가 필요한 내용 질문
4사용자가 음성 답변
5프로젝트 기준으로 결과 생성
기본 요청한 번 쓰고 끝나는 일에 적합합니다.
프로젝트반복되는 글쓰기, 일정 정리, 학습 정리, 보고서 작성에 적합합니다.

프로젝트에서 작업을 시작하는 말하기 예시

새 작업을 시작할게. 이번에 만들 것은 [작업 이름]이야. 프로젝트 지침을 기준으로 진행해줘. 바로 만들지 말고, 필요한 내용을 먼저 한 번에 하나씩 질문해줘. 나는 음성으로 답할게.

4. 프로젝트 지침 입력

프로젝트 지침에는 AI의 역할, 진행 순서, 질문 방식, 답변 형식, 주의사항을 넣습니다. 이렇게 해두면 이후 작업 요청이 훨씬 쉬워집니다.

역할너는 어떤 도우미인가
진행질문 → 음성 답 → 결과
형식표, 목록, 초안, 체크리스트
검토사람이 확인할 기준

프로젝트에 저장할 기본 지침

너는 사용자의 반복 작업을 돕는 AI 도우미야. 사용자는 긴 글을 치지 않고 주로 음성으로 짧게 답한다. 사용자가 작업을 요청하면 바로 결과를 만들지 말고, 필요한 내용을 먼저 질문해라. 질문은 한 번에 하나씩, 쉬운 말로 물어봐라. 사용자의 답이 짧거나 불분명하면 추가 질문으로 확인해라. 필요한 내용을 충분히 들은 뒤에 결과물을 만들어라. 결과는 먼저 초안으로 제시하고, 마지막에는 사람이 확인해야 할 점을 체크리스트로 알려줘라. 개인정보, 민감정보, 확실하지 않은 사실은 반드시 주의 표시를 해라.

프로젝트별로 덧붙일 지침 예시

이 프로젝트는 [예: 여행 계획 / 공지문 작성 / 학습 정리 / 블로그 초안]을 위한 것이다. 결과물은 [표 / 목록 / 문장 / 계획안] 형식을 기본으로 한다. 말투는 [친절하게 / 정중하게 / 쉽게] 작성한다. 최종 답변에는 항상 확인 필요 항목을 포함한다.

5. 음성 답변 받기

이 수업에서는 사용자의 답변이 음성으로 전달된다는 점을 기준으로 설계합니다. 따라서 AI의 질문은 짧고, 한 번에 하나씩, 다시 말하기 쉬워야 합니다.

짧게한 질문에 한 가지
쉽게전문용어보다 생활어
확인애매하면 다시 질문

AI에게 질문 방식을 지정하는 말하기 예시

나는 음성으로 답할 거야. 질문은 짧게 해줘. 한 번에 하나만 물어봐. 내 답이 부족하면 예시를 들어서 다시 물어봐. 내가 답한 내용을 중간중간 한 문장으로 확인해줘.

음성 답변 후 이어서 요청하기

방금 내가 말한 내용을 정리해줘. 빠진 정보가 있으면 먼저 질문해줘. 충분하면 바로 초안을 만들어줘. 초안은 너무 길지 않게 만들고, 마지막에 확인할 점을 알려줘.

6. 답변 검토와 수정

AI 답변은 최종본이 아니라 초안입니다. 받은 답을 음성으로 다시 고치게 하고, 사람이 마지막 확인을 해야 합니다.

  • 내가 말한 목적에 맞는가?
  • 대상과 말투가 맞는가?
  • 빠진 정보나 틀릴 수 있는 사실은 없는가?
  • 개인정보나 민감정보가 들어가지 않았는가?
  • 그대로 사용하기 어색한 표현은 없는가?

음성으로 검토 요청하기

방금 답변을 검토해줘. 목적에 맞는지, 빠진 정보가 있는지, 표현이 자연스러운지, 확인이 필요한 사실이 있는지 봐줘. 결과는 표로 정리하고, 내가 다시 말하면 좋은 수정 요청 문장도 만들어줘.

음성으로 다시 고치기

검토한 내용을 바탕으로 다시 작성해줘. 확실하지 않은 내용은 확인 필요라고 표시해줘. 문장은 더 쉽고 자연스럽게 바꿔줘. 너무 긴 내용은 줄이고 바로 사용할 수 있게 만들어줘.

7. Gemini 노트북 정리

기본 요청에서 잘 된 프롬프트와 프로젝트 지침은 노트북에 저장해두면 다음 수업이나 다음 작업에서 다시 쓸 수 있습니다.

저장 1기본 요청 말하기 틀
저장 2프로젝트 지침
저장 3AI가 물어볼 질문 목록
저장 4검토 체크리스트

노트북 정리 말하기 예시

오늘 만든 기본 요청 흐름과 프로젝트 지침을 노트북에 저장하기 좋게 정리해줘. 제목, 언제 쓰면 좋은지, 마이크에 대고 말할 문장, AI가 물어봐야 할 질문, 확인 체크리스트로 나눠줘.

다음에 다시 쓰기 위한 말하기 예시

지난번에 저장한 프로젝트 지침을 기준으로 새 작업을 시작할게. 내가 하려는 일은 [작업]이야. 필요한 내용을 먼저 질문해줘. 나는 음성으로 답할게.

8. 나의 AI 사용 설명서

마지막에는 내가 AI를 어떻게 사용할지 한 장으로 정리합니다. 핵심은 “내가 다 쓰는 것”이 아니라 “AI가 질문하고 내가 말로 답하는 방식”입니다.

음성으로 나의 AI 사용 설명서 만들기

오늘 배운 내용을 바탕으로 나만의 AI 사용 설명서를 만들어줘. 기본 요청을 할 때의 순서, 프로젝트를 사용할 때의 순서, AI가 나에게 질문해야 할 내용, 내가 음성으로 답할 때 주의할 점, AI 답변을 확인하는 기준을 정리해줘. 문장은 쉽고 실천하기 좋게 써줘.
마무리 문장
AI를 잘 쓰는 사람은 긴 프롬프트를 외우는 사람이 아니라, AI가 필요한 질문을 하게 만들고 자신의 상황을 말로 설명한 뒤 답변을 확인해 고쳐 쓰는 사람입니다.
