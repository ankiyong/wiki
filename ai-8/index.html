1. 오늘 만들 결과물

수업이 끝나면 “삼국지 영상 요약 카드”, “나의 삼국지 지식창고”, “배경과 문구가 바뀐 내 사진”을 남깁니다. 하나만 완성해도 성공입니다.

결과물 1YouTube 영상 링크를 Gemini에 넣고 핵심 내용, 중요한 인물, 확인할 점을 정리합니다.
결과물 2Notebook 이름을 `삼국지`로 만들고, 영상 링크와 요약 결과를 소스로 추가합니다.
결과물 3내 사진을 업로드하고 원하는 배경과 날짜 문구를 넣어봅니다.
핵심 습관처음 결과를 그대로 쓰지 말고 “더 쉽게”, “표로”, “배경만 자연스럽게”처럼 다시 요청합니다.

2. Gemini에서 영상 링크 넣기

Gemini 첫 화면에서 YouTube 링크를 붙여넣고, 원하는 요약 형식을 함께 요청합니다.

실습 프롬프트

이 YouTube 영상을 시니어가 이해하기 쉽게 요약해줘. 1. 영상의 전체 주제를 3줄로 알려줘. 2. 중요한 인물이나 사건을 5개만 골라줘. 3. 어려운 역사 용어는 쉬운 말로 풀어줘. 4. 마지막에는 내가 더 알아보면 좋은 질문 3개를 만들어줘. 링크: https://youtu.be/w0WdLYlYirs?si=x75JjlkBa_MiRF8c

Gemini가 영상을 직접 읽지 못하면 영상 제목, 설명, 자막, 내가 본 내용을 함께 붙여넣고 “실제 영상을 본 것처럼 단정하지 말고 정리해줘”라고 요청합니다.

3. 요약 결과 확인하기

Gemini가 만든 요약은 “완성본”이 아니라 “첫 초안”입니다. 핵심 흐름을 보고 필요한 형식으로 다시 다듬습니다.

확인 1영상 제목·채널이 내가 넣은 링크와 맞는지 봅니다.
확인 2인물 이름, 시대 순서, 소설과 실제 역사 차이를 표시합니다.
확인 3너무 길면 “3줄로”, 어려우면 “초등학생도 이해하게” 다시 요청합니다.

다시 다듬는 프롬프트

방금 요약을 표로 다시 정리해줘. 열은 `구분 / 쉬운 설명 / 더 궁금한 점`으로 해줘. 글씨가 너무 길지 않게 한 칸에 2줄 이내로 써줘.

4. Notebook 지식창고 만들기

영상 요약을 그냥 지나치지 않고 Notebook에 모아두면, 나중에 다시 질문할 수 있는 개인 자료함이 됩니다.

1

이름을 `삼국지`로 지정

새 Notebook을 만들고 수업에서 계속 찾기 쉽도록 제목을 먼저 정합니다.

수강생 안내: 제목은 짧게, 오늘 주제와 바로 연결되게 적습니다.
2

`소스 추가` 선택

Notebook이 참고할 자료를 넣기 위해 소스 추가 버튼을 누릅니다.

막히면 강사 화면을 보고 같은 위치의 버튼을 천천히 찾습니다.
3

`웹사이트`에 YouTube 링크 입력

복사한 YouTube 주소를 웹사이트 입력칸에 붙여넣어 영상 자료를 연결합니다.

링크 입력이 안 되면 Gemini 요약문을 메모장에 저장하는 방식으로 대체합니다.
4

뒤로 돌아와 Gemini에게 질문

소스를 넣은 뒤 다시 채팅 화면으로 돌아와 삼국지 내용을 쉽게 설명해 달라고 묻습니다.

예: “유비, 관우, 장비를 쉽게 비교해줘.”

Notebook에 넣을 내용

영상 링크오늘 사용한 YouTube 주소
요약문Gemini가 정리한 3줄 요약
내 질문다음에 더 알고 싶은 질문 2개

Notebook 접속이나 로그인이 어렵다면 휴대폰 메모장, Google Docs, 카카오톡 나에게 보내기로 대체해도 됩니다.

5. 지식창고에 다시 물어보기

Notebook에 자료를 넣은 뒤에는 “삼국지 공부 노트”처럼 다시 질문하며 내용을 쉽게 바꿔볼 수 있습니다.

실습 프롬프트

아래 내용을 바탕으로 나만의 삼국지 지식창고 첫 페이지를 만들어줘. 구성은 다음 순서로 해줘. 1. 오늘 본 영상 2. 한눈에 보는 핵심 내용 3. 중요한 인물 4. 어려운 단어 쉬운 풀이 5. 다음에 더 알아볼 질문 문장은 짧고 쉽게 써줘.
질문 예시유비, 관우, 장비를 아주 쉽게 비교해줘.
질문 예시소설 삼국지와 실제 역사는 어떤 점이 다를 수 있어?
질문 예시손주에게 설명한다고 생각하고 1분 이야기로 만들어줘.
주의자료에 없는 이야기를 지어내지 않는지 확인합니다.

6. 내 사진 준비와 업로드

사진 편집은 재미있지만 개인정보가 될 수 있습니다. 본인 사진을 쓰고, 공개해도 괜찮은 사진인지 먼저 확인합니다.

사진 선택 기준

  • 얼굴과 상반신이 너무 작지 않은 사진
  • 다른 사람 얼굴, 손주 사진, 주소·차량번호가 보이지 않는 사진
  • 집 앞, 병원, 금융기관처럼 민감한 장소가 드러나지 않는 사진
  • 단체방이나 SNS에 올리기 전 다시 확인할 수 있는 사진

AI 도구에 올린 사진은 서비스에 따라 저장되거나 학습에 사용될 수 있으니 민감한 사진은 올리지 않습니다. 수업 중 공유도 강요하지 않습니다.

7. Gemini로 배경과 문구 바꾸기

핵심은 “사람은 그대로, 배경만 변경”입니다. 문구와 날짜는 AI가 한글을 틀릴 수 있으므로 필요하면 스마트폰 사진 편집 기능으로 넣습니다.

원본: 복잡한 배경
변경 후: 공원·한옥마을·카페

기본 실습 프롬프트

이 사진에서 사람은 그대로 자연스럽게 유지하고, 배경을 따뜻한 가을 공원으로 바꿔줘. 사진 분위기는 밝고 편안하게 해줘.

문구와 날짜 넣기

사진 아래쪽에 작고 단정한 글씨로 `2026.08.13 공주시 평생학습관 AI 수업`이라는 문구를 넣어줘. 사람 얼굴을 가리지 않게 해줘.

한글이 깨지거나 틀리면 괜찮습니다. 그럴 때는 AI로 배경만 바꾸고, 글씨는 스마트폰 갤러리·카카오톡 편집·Canva 등으로 직접 넣습니다.

8. 비교·저장·마무리

AI 결과는 첫 답이 완성이 아니라, 내가 다시 요청하며 다듬는 초안입니다. 저장하기 전 원본과 비교합니다.

YouTube 요약 확인영상 내용과 다른 말이 없는지, 중요한 내용이 빠지지 않았는지 확인합니다.
Notebook 확인내가 넣은 자료를 기반으로 답하는지, 출처 없는 이야기를 지어내지 않는지 봅니다.
사진 결과 확인얼굴, 손, 머리카락, 옷, 배경 경계가 어색하지 않은지 봅니다.
저장마음에 드는 결과와 좋은 프롬프트를 저장합니다.

마무리 프롬프트

오늘 만든 YouTube 요약, Notebook 지식창고, 배경 변경 사진을 다시 검토해줘. 수업 과제로 제출하기 좋게 제목, 한 줄 설명, 내가 배운 점 3가지를 정리해줘.
